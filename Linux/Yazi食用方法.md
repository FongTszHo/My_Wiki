# 🦆yazi简易使用方式

## 一、yazi操作类
| 操作     | 快捷键           |     |
| :----- | :------------ | --- |
| 打开yazi | `y`（或者`yazi`） |     |
| 关闭yazi | `q`           |     |

## 二、文件操作类
| 操作       | 快捷键 |     |
| :------- | :-- | --- |
| **创建文件** | `a` |     |
| **复制文件** | `y` |     |
| **剪贴文件** | `x` |     |
| **粘贴文件** | `p` |     |
| **查找文件** | `z` |     |
