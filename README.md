## 🗺️ 知识地图 (Knowledge Map)

我的学习路径主要分为以下四个维度：

### 1. 🦾 机器人与仿真 (Robotics & Simulation)
*核心领域：机器人操作系统与物理仿真*
- **ROS**: 机器人操作系统学习笔记与节点开发。
- **Mujoco**: 物理引擎仿真学习，记录 `Mujoco学习记录` 与相关实验。

### 2. 💻 嵌入式与硬件 (Embedded Systems)
*核心领域：底层驱动与硬件控制*
- **STM32**: 基于ARM Cortex-M的开发笔记。
- **ESP32**: 物联网与WiFi/蓝牙应用开发。

### 3.  Linux 系统与实战 (Linux & System)
*核心领域：系统底层与驱动开发*
- **工具与技巧**:
    - `using_yazi`: 终端文件管理器 Yazi 的使用心得。
    - `我的Linux踩坑记`: 记录在Linux环境配置、驱动编译中遇到的坑与解决方案。

### 4. 🧠 AI 与编程 (AI & Coding)
*核心领域：上层应用与智能体*
- **AI_Agent**: 探索 Claude Code 等AI编程助手的安装与使用，构建智能体。
- **Code/Python**: Python 编程基础与算法实现。
